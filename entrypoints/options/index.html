Quick Stamp for GitHub

Adds an Approve button to the “Review required” row of the pull request merge box. Approvals are submitted through the GitHub API with a personal access token, stored only in this browser.

Creating a token

  • Classic token with the repo scope (public_repo is enough for public repositories).
  • Fine-grained token with Pull requests: Read and write. The owning organization may need to allow or approve fine-grained tokens.
